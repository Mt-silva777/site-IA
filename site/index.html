Três painéis, um objetivo

Tudo roda no seu computador. Você escreve, o aplicativo executa, e a professora acompanha o arquivo que você está editando.

⌨️

Editor e terminal reais

Editor Monaco (o mesmo núcleo do VS Code) com abas, explorador de arquivos e um terminal que executa comandos de verdade.

🧑‍🏫

Professora de IA

Lê somente o arquivo aberto, em modo leitura. Explica, pergunta e dá pistas — não escreve nem altera o seu projeto.

🌐

Preview ao vivo

O site aparece ao lado do código e atualiza sozinho a cada mudança, em visão desktop, tablet ou celular.

Uma professora, não um gerador de código

Quando você comete um erro, a professora aponta onde olhar e faz uma pergunta. As pistas vêm aos poucos, e a resposta final continua sendo sua.

let idade = 15;

if (idade > 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}
ProfessoraObserve a condição que você usou. O que acontece quando a idade é exatamente 18? A sua comparação cobre esse caso?

Exemplo ilustrativo do comportamento planejado. A integração com a IA (Gemini) ainda não foi implementada.

Acompanha sem atrapalhar — e sem gastar à toa

A IA não fica analisando cada tecla. Problemas simples são tratados localmente; a API só é chamada quando há um motivo relevante.

SituaçãoO que acontece
Ponto e vírgula, indentação, erro de digitaçãoSinalizado no editor. Sem chamar a IA.
Chave ou parêntese ainda abertoAguarda você terminar de digitar.
Erro persistente, lógica incorreta, site que não funcionaPode acionar a professora, com limite de chamadas.
Código correto com algo a aprenderComentário pedagógico ocasional.

Tecnologia e segurança

A regra pedagógica é aplicada na arquitetura, não só no texto do prompt: a IA simplesmente não tem ferramentas de escrita nem de execução.

  • Electron + React + TypeScriptAplicativo desktop com interface moderna.
  • Monaco Editor · xterm.jsEditor e terminal de nível profissional.
  • ViteServidor de desenvolvimento com atualização instantânea.
  • Google Gemini (@google/genai)Provedor de IA atrás de uma camada de abstração.
  • Chave protegidaFica no processo principal, nunca na interface.
  • Acesso restrito a arquivosCaminhos validados; exclusão vai para a lixeira.
